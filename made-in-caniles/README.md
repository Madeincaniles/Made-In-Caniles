# Made In Caniles
Tienda estática preparada para GitHub Pages.

## Publicar gratis
1. Crea un repositorio nuevo en GitHub, por ejemplo `made-in-caniles`.
2. Sube **todo el contenido** de esta carpeta (index.html, style.css, script.js y la carpeta assets).
3. En el repositorio: Settings > Pages.
4. En “Build and deployment”, elige “Deploy from a branch”.
5. Selecciona `main` y `/ (root)` y guarda.
6. GitHub mostrará la dirección pública de la tienda.

## Editar productos
Los productos están definidos al principio de `script.js`.
